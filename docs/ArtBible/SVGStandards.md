# SVG Standards

## Canvas
480 x 600

## Requirements
- Transparent background (unless background layer)
- Group IDs for every logical part
- No raster images
- No scripts
- Modular construction
- Compatible with Illustrator and Inkscape

## Lighting
Single top-left light source.

## Outlines
Never pure black.
Use darker local colours.

## Naming
body.svg
outfit.svg
equipment.svg
accessory.svg
effects.svg
ornament.svg
