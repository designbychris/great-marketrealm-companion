# Portrait Style Guide

## Vision
Portraits should feel warm, whimsical and hand-crafted.

## Core Principles
- Friendly before realistic.
- Round before sharp.
- Colourful before muted.
- Storybook fantasy.
- Nintendo-inspired charm.

## Portrait Layer Order
1. Background
2. Character Shadow
3. Body Base
4. Body Shadows
5. Body Highlights
6. Face
7. Eyes
8. Mouth
9. Hair / Leaves
10. Clothing
11. Equipment
12. Accessories
13. Foreground Effects
14. Frame

## Expression
Small changes to eyes and mouth should create many personalities.
