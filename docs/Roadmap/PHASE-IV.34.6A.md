# Phase IV.34.6A — The Chronicle Opens Its Pages

The Companion now receives the Tabletop Keeper recap and character-attributed deed ledger when a linked Session ends. Company Chronicle entries remain compact summaries and link to a dedicated shared Session page where Fellowship members can read the full record and add clearly separated player memories. ISO dates remain canonical in storage; user-facing Session and Chronicle dates use the reusable MarketRealm date presenter.
