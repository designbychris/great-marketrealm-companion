# Phase III.16.7A — Field Guide Publication Pass

The first player-safe shelf of the Guild Field Guide is now published from the canonical Bestiary.

## Publication contract

- The Dungeon Master Guide remains the canonical creature source.
- A separate publication map contains only player-safe lore.
- Published entries receive `field_guide_visible` and `player_description` before Steward overrides are applied.
- Steward overrides remain authoritative, so an administrator can hide a seeded entry or replace its player description.
- Artwork continues to come from the existing canonical Bestiary image attachment, avoiding duplicate media records.
- No AC, HP, CR, ability scores, attacks, traits, actions or DM notes are stored in the publication map.

## First shelf

The first publication pass includes the twelve canonical creatures whose source register already contains suitable non-mechanical descriptive lore, including the Pickled Basilisk benchmark. Records without sufficiently safe source description remain unpublished rather than having lore invented for them.

This gives the Field Guide useful content immediately while preserving the spoiler-safe boundary established in III.16.7.
