# Phase III.16.20E.1 — Heritage Availability & Rootkin Canonical Import

This follow-up to III.16.20E imports the Rootkin Heritages authored in
The Great Marketrealm – Players Handbook into the bundled canonical
Character Catalogue and improves the Character Builder when a Folk has
no Heritage choices.

## Canonical Rootkin Heritages

- Carrotfolk — The Keenroots
- Potatofolk — The Stoutroots
- Onionfolk — The Many-Layered
- Garlicfolk — The Pungent
- Parsnipfolk — The Deeproots

The import keeps structured ability modifiers, supported proficiencies,
speed where applicable, proficiency choices, and named feature guidance.
Specialised rules remain represented as named feature guidance until a
dedicated executable mechanic exists.

## Heritage availability

The Character Builder now hides and disables the Heritage selector when
the selected Folk has no matching Heritage records. Switching back to a
Folk with Heritages restores the selector and its live guidance.

## Catalogue refresh

The bundled Catalogue advances from 3.7.5 to 3.7.6 so existing WordPress
installations reseed the canonical Rootkin Heritage data.
