# Phase III.16.4A — The Living Bestiary

The canonical Marketrealm Bestiary now carries richer Dungeon Master Guide rules into each illustrated creature folio while preserving the immutable-guide + Steward-override architecture established in Phase III.16.4.

## Certified scope

- Rich canonical rule fields: saving throws, skills, resistances, immunities, vulnerabilities, senses and languages.
- Advanced rule sections: spellcasting, reactions, legendary actions, mythic features and lair actions.
- Pickled Basilisk is the benchmark complete folio; Croissant Dragon proves legendary-creature rendering.
- Existing canonical records remain usable when the Guide omits a field; nothing is inferred to fill source gaps.
- Steward overrides can tune every new Living Bestiary field and can still be reset to the Dungeon Master Guide baseline.
- Encounter snapshots remain intentionally unchanged and continue to capture combat-safe values only.

The torn-paper artwork silhouette remains a separate visual-polish concern and is not expanded by this mechanics/data pass.
