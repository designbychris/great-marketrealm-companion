# Guild Ledger UI Kit

Version: 0.1  
Status: Living Document

> The Guild Ledger should feel less like software and more like a
> treasured object that remembers every adventure.

## Purpose

The Guild Ledger UI Kit is the canonical visual component library for
the Great Marketrealm Companion.

It translates the principles established in `DESIGN_BIBLE.md` into
reusable application components.

All new interface work should use these components wherever possible.

---

## Design principles

The UI Kit should:

- Feel like an enchanted recipe book.
- Use warm and tactile visual materials.
- Remain readable and accessible.
- Work without decorative images or animation.
- Use semantic HTML.
- Provide visible keyboard focus states.
- Remain fully usable on mobile devices.

The UI Kit should not:

- Resemble the WordPress administration area.
- Depend on harsh white surfaces.
- Use generic dashboard cards without an in-world purpose.
- Sacrifice usability for decoration.
- communicate important information through colour alone.
