# Spanish language pack (`es_ES`)

The Companion Spanish tester-review pack targets **Spanish (Spain)** using the WordPress locale `es_ES`.

The pack translates the application interface, controls, helper copy and curated MarketRealm interface voice. Canonical character names, campaign names and authored rules/content remain separate from interface localisation.

Files:

- `languages/great-marketrealm-companion-es_ES.po` — editable Spanish catalogue.
- `languages/great-marketrealm-companion-es_ES.mo` — compiled catalogue loaded by WordPress.

The per-user Guild Profile language selector exposes the locale as **Español** and shares the same `gmrc_interface_locale` preference with Tabletop.
