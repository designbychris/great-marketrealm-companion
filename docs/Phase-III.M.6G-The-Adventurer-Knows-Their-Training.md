# Phase III.M.6G — The Adventurer Knows Their Training

The native Pocket Character tab now presents the character's authoritative saving throws and skills.

- Saving throws show their resolved modifier and proficiency state.
- Skills show their canonical label, governing ability, resolved modifier, proficiency, and expertise.
- The Pocket API remains the source of resolved mechanics; native code does not calculate proficiency or expertise bonuses.
- Training is read-only in this phase. Rolling is intentionally deferred to III.M.6G.1.
- No native character database or offline character writes are introduced.
