# Phase III.16.8A — Background Mechanics Bridge

## Incoming certified baseline

- 3,561 tests
- 12,381 assertions
- all green

## Purpose

Connect Steward-managed optional Handbook Background proficiencies to future Character creation without rewriting existing Character mechanics.

## Certified rules

- The Players Handbook transcription remains immutable.
- Steward overrides may choose exactly two valid skills and one valid tool proficiency.
- The Character Generator and Guild Library resolve the same current canonical Background mechanics.
- New Characters persist the selected Background skill/tool mechanics as a Character-owned snapshot.
- Existing Characters without a snapshot continue to use the bundled baseline they were created against; later Steward changes never rewrite them.
- Resetting a canonical Background removes the Steward overlay and restores the Handbook baseline for future Characters.

## Deferred source gaps

Languages, equipment and starting wealth remain unfilled where the Handbook does not specify them.
