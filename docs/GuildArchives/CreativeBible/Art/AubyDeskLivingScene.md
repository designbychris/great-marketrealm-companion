# Auby's Living Desk

The Desk should feel like a view into Auby's actual corner of the Guild Hall. The illustration owns the left side of the composition and dissolves into warm Guild brown on the right.

The brown panel contains `AUBY'S DESK`, `Someone has been busy.`, contextual activity text and one torn Auby Sticky Note.

Static paintings may be enhanced by subtle CSS overlays for tea steam, floating dust, window glow, lamp glow, stars and late-night sleeping Zs. All ambient motion must respect reduced-motion preferences.
