# Auby Desk Hero Library

Phase II.2 establishes the first complete hero scene library for Auby's Desk.

## Dayparts

- Dawn — welcoming, first tea.
- Morning — focused, writing.
- Afternoon — quizzical, thinking.
- Evening — relaxed, reading.
- Night — thoughtful, late tea.
- Late Night — asleep.

All six scenes share the same Guild Hall visual language and are intended to
fill the illustrated side of the Living Desk composition.

## Runtime

The active scene is selected from the visitor's local browser hour using the
existing manifest-backed resolver.

Only Late Night may enable the `sleep` ambient effect.
