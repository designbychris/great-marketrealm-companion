# Open Ledger Visual Language

The Ledger should feel handled, recorded and cared for.

## Materials

- warm parchment;
- cocoa leather;
- purple ribbon;
- faded ink;
- restrained Guild gold;
- handwritten annotations.

## Hierarchy

The character portrait is the visual anchor of the first page.

The name should feel handwritten into the Guild Register rather than rendered
as an application title.

Numbers should remain highly legible even when surrounded by storybook
details.

## Rule

Decorative objects must never obscure character data.

The player should be able to scan Armour Class, Hit Points, Ability Scores,
Saving Throws and Skills as quickly as they could on a conventional character
sheet.
