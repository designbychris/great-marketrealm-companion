# Complete Registration — UI Language

Registration is ceremonial, not bureaucratically slow.

The player is inscribing a Guild record rather than stepping through a generic
wizard.

- conditional choices appear only when required;
- ability scores remain highly scannable;
- the final review resembles a small Ledger page;
- the final action is **Seal the Guild Record**;
- Auby supports the moment without obscuring rules or errors.
