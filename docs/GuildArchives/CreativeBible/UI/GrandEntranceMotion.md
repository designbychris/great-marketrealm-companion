# Grand Entrance Motion Language

The Grand Entrance is not a generic `slideDown`.

It should feel like a small leather-and-wood Guild case has physically been
placed at the top of the interface.

## Character

- weighted rather than floaty;
- cheerful rather than slapstick;
- one confident impact;
- one visible rebound;
- one tiny settle;
- then absolute stillness.

Global interface movement must remain rare. The entrance is memorable because
the rest of the Companion does not constantly bounce.
