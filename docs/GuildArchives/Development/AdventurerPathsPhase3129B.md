# Phase III.12.9B — The Ranger's Paths

This phase establishes the eight canon Ranger Paths supplied for the Great
Marketrealm and connects them to the shared specialist Path architecture.

## Certified Paths

- Aislewarden Conclave
- Deep-Root Warden
- Cold Vault Stalker
- Conclave of the Forager
- Spice Trail Hunter
- Rindrunner
- Seedshot Conclave
- Expiry Hunter

Rangers select a Path at Level 3.

Each Path has its supplied Level 3, 7, 11 and 15 features represented as
automatic Path Gifts. The wording and numerical mechanics are derived from
the supplied Ranger material rather than substituted with standard D&D
subclasses.

## Choice preview

Each Path now has player-facing identity, playstyle and best-for guidance.
The shared character creation/edit subclass preview can therefore explain
the eight choices before a player commits.

The preview also exposes the four supplied feature milestones.

## Active mechanics boundary

This phase certifies identities and feature rules. It deliberately does not
yet build dedicated interactive spenders/selectors for mechanics such as:

- Grasping Roots uses;
- Forager's Remedies;
- Spice Infusions;
- Seedshots;
- Put It Back uses;
- Ancient Rind uses.

Those can be layered onto the certified Path data in subsequent Ranger
active-play slices without changing Path identity.

## Catalogue invalidation

The bundled character catalogue advances from 3.7.3 to 3.7.4 so existing
WordPress option snapshots are invalidated and the eight Ranger Paths become
visible immediately after deployment.
