# Phase III.12.6B — The Paladin's Sacred Oaths

III.12.6B promotes all eight Sacred Oaths into certified specialist
progression paths.

## Sacred Oath cadence

Every Oath now grants an automatic Path Gift at:

- Level 3
- Level 7
- Level 15
- Level 20

This matches the progression boundary reserved in III.12.6.

## Shared presentation

The gifts are registered through `PathGiftCatalogue`, so they automatically
flow into:

- Level-up Path Gift certification;
- the Guild Record;
- Sacred Oath advancement choice previews;
- the Character Creator's Future path / subclass preview.

There is no duplicate creation-only gift catalogue.

## Mechanical boundary

III.12.6B certifies identity, progression and player-facing descriptions.

It does not yet spend:

- Lay on Hands;
- Divine Sense;
- spell slots;
- Divine Smite;
- Cleansing Touch.

Those remain assigned to the later Paladin active-play phases.
