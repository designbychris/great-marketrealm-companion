# Character Lifecycle Initiative — Phase III.6: The Rising Register

The Rising Register completes the existing Character progression model rather than creating a parallel store. Earned XP is recorded first; once the existing Experience Table threshold is met, the player deliberately certifies the next level. Certification advances one level, grows HP by fixed-average class Hit Die + Constitution modifier, and persists through the existing Character repository. Proficiency, attacks, saving throws, skills, spell slots and level-gated abilities then derive from the new level automatically.
