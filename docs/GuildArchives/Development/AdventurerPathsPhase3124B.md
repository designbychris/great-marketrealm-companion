# Phase III.12.4B — The Rogue's Archetypes

III.12.4B turns the six repository-defined Rogue Archetypes into complete
Companion specialist progressions.

## Source boundary

The player catalogue supplied these six names and Rogue parent relationships,
but its Rogue `traits` arrays are empty.

The gift names, descriptions and playstyle guidance in this phase are
therefore **Companion-authored Great Marketrealm material**, not extracted
rules from the source catalogue.

## Choice guidance

Each Rogue Archetype now has:

- identity;
- playstyle;
- best-for guidance;
- four-gift progression preview.

This directly follows the player-feedback rule established during Barbarian:
a specialist choice should explain what the path feels like before the player
commits to it.

## Certification

The standard Rogue Archetype gift cadence is:

`3 → 9 → 13 → 17`

All current gifts are automatic progression gifts.

Level 3 now delegates both the Rogue Archetype choice and its first Path Gift.
Later Rogue gift hand-offs already reserved by III.12.4 occur at 9, 13 and 17.

## Ledger

The Cunning Register now displays **Certified Rogue Archetype Gifts**.

Only gifts persisted on the Character are displayed. Future gifts are not
shown as though already earned.

## Future boundary

III.12.4B describes and certifies Archetype progression. It does not yet turn
every gift into an active button or resource.

Interactive Cunning Action and precision/reaction state remain reserved for:

- III.12.4C — The Rogue's Cunning Actions
- III.12.4D — The Rogue's Precision & Reactions
