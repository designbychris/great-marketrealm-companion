# Phase III.7.2.2.1 — Dice Table Breathing Room

The Dice of Destiny controls originally inherited the six-column
Complete Registration ability layout.

Once each ability contained three dice, a roll button, maths and a
modifier, that desktop row became visually cramped.

The Dice of Destiny table now uses:

- 3 columns on desktop, producing two rows of three abilities;
- 2 columns at 1050px and below;
- 1 column at 680px and below.

This is a presentation-only correction. Dice generation, validation
and Character persistence are unchanged.
