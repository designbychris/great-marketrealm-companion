# Phase III.12.8C — Font of Magic / Sorcery Reserves

III.12.8C turns the Sorcerer's Level 2 Font of Magic foundation into a
persistent active-play reserve.

## Sorcery Points

From Sorcerer Level 2 onward:

- maximum Sorcery Points equal Sorcerer level;
- expenditure is stored in the shared active class resource ledger;
- the Origin Spark Register displays remaining and maximum points;
- a long rest restores the Sorcery Point reserve.

Permanent maximums remain progression-owned. The active ledger stores only
expenditure.

## Flexible Casting

The Ledger now supports both directions of Flexible Casting.

### Sorcery Points to spell slot

A Sorcerer can recover one expended standard spell slot by paying:

- Level 1 slot — 2 points
- Level 2 slot — 3 points
- Level 3 slot — 5 points
- Level 4 slot — 6 points
- Level 5 slot — 7 points

The Companion does not allow the persistent shared slot reserve to exceed its
certified maximum. Font of Magic therefore restores an expended slot rather
than creating a permanent extra slot identity.

### Spell slot to Sorcery Points

An available standard spell slot can be spent to recover Sorcery Points equal
to the slot's level, capped naturally by the Sorcerer's certified point
maximum.

## Long rest

The Sorcerer long-rest action restores:

- Sorcery Points;
- standard spell slots.

## Phase boundary

III.12.8C does not implement Metamagic selection or Metamagic actions. Those
remain a later Sorcerer slice.

Origin Gift mechanics remain separate from this reserve slice.

## Accessibility and layout

Font of Magic controls use ordinary labelled forms and native inputs/selects,
remain keyboard operable without JavaScript, stack responsively, and retain
forced-colours support.
