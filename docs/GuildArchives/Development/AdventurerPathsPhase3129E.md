# Phase III.12.9E — The Ranger's Final Seal

III.12.9E certifies the Ranger Calling across III.12.9 through III.12.9D.

## Certified Ranger stack

The Final Seal protects:

- specialist Ranger advancement;
- Favoured Mark and Natural Explorer foundations;
- Wisdom-based known-spell half casting;
- shared standard spell slots;
- Ranger Field Register;
- Level 3 Ranger Path selection;
- eight canon Great Marketrealm Ranger Paths;
- four supplied Path feature milestones at Levels 3 / 7 / 11 / 15;
- source-defined finite Field Reserves;
- long-rest recovery;
- Ranger Field Arts;
- shared Guild Diceworks integration;
- responsive, reduced-motion and forced-colours-safe Ledger presentation.

## Eight sealed Paths

- Aislewarden Conclave
- Deep-Root Warden
- Cold Vault Stalker
- Conclave of the Forager
- Spice Trail Hunter
- Rindrunner
- Seedshot Conclave
- Expiry Hunter

## Source-faithful mechanics

The Final Seal explicitly protects the rule that the Companion must not invent
missing Ranger quantities.

Examples deliberately left undefined include:

- Forager remedy preparation count;
- Nettle Oil poison damage die;
- Seedshot ammunition count;
- Burstmelon Seed damage formula;
- Bloom Seed healing amount.

Where the supplied canon gives a number or formula, the Companion preserves
it. Where it does not, the Ledger presents descriptive guidance only.

## Field Reserves

Only explicitly finite-use Path mechanics receive persistent counters.

Maximums remain derived from permanent character state or fixed source rules.
The active class resource ledger stores expenditure only.

The Field Reserve service restores only Ranger Path resources. The Ranger
controller then restores shared spell slots separately during the complete
Field Long Rest flow. This keeps resource ownership clean.

## Field Arts and Diceworks

Ranger damage and healing formulas use the shared Guild Diceworks triggers.

The Final Seal does not introduce a Ranger-specific dice engine.

Notable protected formulas include:

- Aislewarden quarry damage: 1d6 → 1d8;
- Deep-Root Thornroad: 1d6 piercing;
- Heart of the Rootlands: 2d8 plus Wisdom modifier;
- Cold Vault Frost-Tipped Hunter: 1d6 cold;
- Cold Vault Shattering Shot: 2d6 cold;
- Spice Infusion: 1d6 → 2d6;
- Final Seasoning: four separate 2d6 typed rolls;
- Rindrunner Piercing Wedge: 1d8;
- Expiry Mark: 1d8 radiant or 1d8 necrotic;
- Sagebrew: 1d4 check bonus.

## Browser hardening

The Final Seal adds additional protection for narrow layouts, long Path labels,
large action text and typed roll controls.

It also reinforces:

- minimum comfortable button height;
- reduced-motion compatibility;
- forced-colours button visibility;
- single-column slot presentation on very narrow screens;
- wrapping rather than horizontal overflow.

The Ranger is therefore certified as a complete specialist Calling at the end
of III.12.9E.
