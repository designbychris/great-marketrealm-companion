# Phase III.10.6.2 — The Ledger Tabs Settle In

This micro-polish phase finishes the visual move of the main Character Ledger index.

## Final placement

The seven main Ledger tabs now:

- begin at the left edge of the book;
- sit directly against the book's top edge;
- use rounded top corners and square/open bottoms;
- keep the active tab visually connected to the open Ledger;
- no longer appear inside a separate floating toolbar;
- retain the existing mobile grid fallback.

The structural “Guild Ledger Index” label remains available to assistive technology but is visually hidden so the tab rail itself becomes the book furniture.

## Scope

This phase changes presentation only. It does not alter:

- ARIA tab semantics;
- keyboard navigation;
- active panel behaviour;
- query-string tab restoration;
- Arcane Pantry nested tabs;
- Diceworks;
- Vital Measures;
- Character state.
