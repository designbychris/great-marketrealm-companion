# Phase III.12.9C — The Ranger's Field Reserves

III.12.9C turns the finite-use abilities explicitly defined in the supplied
Ranger Path material into persistent active-play resources.

## Source-first reserve rule

A Field Reserve is only created when the supplied Ranger rules state a
specific finite use maximum.

The Companion does not infer or fabricate missing counts.

## Certified reserves

### Deep-Root Warden

- Grasping Roots — Proficiency Bonus uses per long rest from Level 3.
- Heart of the Rootlands — once per long rest from Level 15.

### Conclave of the Forager

- Miracle Harvest — once per long rest from Level 15.

The supplied material says higher levels allow more prepared remedies and
improve potency, but it does not define a preparation-count progression.
III.12.9C therefore does not invent one.

### Spice Trail Hunter

- The Final Seasoning — once per long rest from Level 15.

Spice Infusion itself has no supplied use maximum and remains non-reserve
Path functionality.

### Rindrunner

- Ancient Rind — Wisdom modifier uses per long rest from Level 15.

The supplied rule says exactly `Wisdom modifier`; the Companion does not
silently add a minimum-one rule.

### Seedshot Conclave

- Ancient Seed — once per long rest from Level 15.

The supplied Seedshot feature defines known ammunition types but no ammunition
use count. Seedshot quantities are therefore not invented in this phase.

### Expiry Hunter

- Put It Back — Proficiency Bonus uses per long rest from Level 11.

### Aislewarden Conclave and Cold Vault Stalker

Neither supplied Path defines an explicitly finite-use resource. No counter is
fabricated.

## Persistence

Field Reserve maximums are derived from permanent character progression:

- proficiency bonus;
- Wisdom modifier;
- fixed once-per-long-rest rules;
- Path and level gates.

The shared active class resource ledger stores expenditure only.

## Long rest

The Ranger Field Rest action restores all finite reserves belonging to the
character's currently certified Path.

The controller also restores the Ranger's standard spell slots as part of the
same long-rest action.

## Accessibility

Every finite reserve is presented with remaining / maximum state and an
ordinary server-backed spend button. The long-rest action is also server
backed, keyboard operable without JavaScript, responsive and forced-colours
safe.
