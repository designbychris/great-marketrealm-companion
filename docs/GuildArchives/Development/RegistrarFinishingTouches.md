# Character Lifecycle Initiative — Phase III.1: The Registrar’s Finishing Touches

Phase III.1 is the polish bridge between Complete Registration and the finished
Character lifecycle.

## Register prompt

The empty Register and populated Register now use the same reusable
`register-adventurer-prompt` component.

The empty state is presented as a deliberately blank Guild page rather than a
generic application empty-state card.

## Create Adventurer

The workflow and validation logic from Complete Registration are unchanged.

The Registrar now uses the same parchment, handwritten display type, aubergine
ribbon, Guild gold and physical-page language as The Open Ledger and Final
Farewell.

## Living Portrait alignment

Generation 2 eyes and painted eyelids now participate in the same breathing
motion as the remaining face layers.

Blinking is a paint swap only. It no longer applies a separate transform, so
the Apple Fructan face remains aligned in both Portrait Studio and Open Ledger.

## Auby Desk high-resolution restoration

Four genuinely different desk illustrations are restored:

- Morning;
- Afternoon / daytime;
- Evening;
- Late Night.

The runtime hero dimensions are 2560 × 1584.

The six dayparts remain backward compatible:

- Dawn aliases Morning;
- Night aliases Late Night.

This preserves existing schedules, tests and ambient copy without returning to
six near-identical illustrations.
