# Phase III.13.5 — Relics of the Marketrealm

**Status:** Implemented — awaiting server certification.

The Guild Library now records 19 magical items from the canonical Player's Handbook:
protective wonders, magic items, magical foil armour, legendary armour and legendary weapons.

The Relic Register is deliberately reference-first. Its special powers are shown exactly
as records for players and DMs; Character Inventory does not silently automate attunement,
charges, recharge rolls, immunities, spell reflection, teleportation or other exceptional
effects.

The no-character Guild Library artwork is the shared Library backdrop. The Auby Library
artwork marks the restricted Relic Archive. The Sage artwork is installed for future
knowledge-focused Library presentation.

Incoming certified baseline: 3,336 tests / 10,915 assertions.
