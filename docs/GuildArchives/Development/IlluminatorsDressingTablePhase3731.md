# Character Lifecycle Initiative — Phase III.7.3.1
## The Illuminator's Dressing Table

This phase is a presentation-only pass for Portrait Customisation on the
Character Creation screen.

It deliberately leaves the green III.7.2.3 Workbench JavaScript contracts
untouched.

### Visual direction

The creator now borrows the Guild Ledger's established language:

- parchment work surface;
- cocoa controls;
- Guild purple randomisation controls;
- brass/gold focus and ornamental details;
- framed variant rows;
- pill-shaped variant counters;
- matched full-width Randomise and Reset actions;
- deliberate locked/single-set presentation.

### Accessibility

- visible gold `:focus-visible` treatment remains present;
- controls retain their semantic button behaviour;
- mobile controls collapse without losing labels or counters;
- reduced-motion users do not receive hover movement.

### Scope

This phase changes presentation only. Portrait asset expansion belongs to
Phase III.7.3.2 — The Great Portrait Expansion.
