# Character Lifecycle Initiative — Phase II: The Open Ledger

The saved-character screen is no longer treated as a generic application
detail page. It is rendered as the adventurer's physical Guild Ledger.

## First spread

Page I is the identity record:

- illuminated portrait;
- Guild seal;
- character name;
- race;
- class;
- level;
- background;
- experience;
- register reference;
- small Auby annotation.

Page II records adventuring measures:

- Armour Class;
- Initiative;
- Speed;
- Proficiency Bonus;
- Passive Perception;
- Ability Scores;
- Hit Points;
- Saving Throws.

## Second spread

Page III contains:

- Skills;
- Background;
- background skill proficiencies;
- unresolved language choices.

Page IV contains:

- Languages;
- Tool Proficiencies;
- Conditions;
- placeholders for Project Leather Satchel, character Features and Guild
  Honours.

## Character lifecycle

The Ledger retains:

- Return to Register;
- Edit Adventurer;
- Delete Adventurer → The Final Farewell.

## Responsive behaviour

Desktop and large tablet display the record as a true two-page open book.

Below 820px each page becomes an individual parchment sheet. This prevents the
book metaphor from forcing tiny columns on tablet/mobile and gives the future
responsive polish pass a stable foundation.
