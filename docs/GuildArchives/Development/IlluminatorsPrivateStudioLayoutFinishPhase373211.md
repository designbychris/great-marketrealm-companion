# Character Lifecycle Initiative — Phase III.7.3.2.1.1
## The Private Studio Layout Finish

A small presentation correction closes the Private Studio move before the
Guild Wardrobe begins.

### Character Creation

The Dressing Table no longer forces label, three controls and counter onto one
line. Each layer now uses:

1. a full-width label row;
2. Previous / Randomise / Next / variant position beneath it.

This removes the collision visible on labels such as Background and Equipment.

### Character Ledger

The finished Guild portrait and Bring Your Own Portrait toolkit share a compact
two-column desk on desktop:

- portrait on the left;
- custom-upload toolkit on the right.

Below 920px the desk stacks back to one column.

No portrait runtime or persistence behaviour changes in this patch.
