# Character Lifecycle Initiative — Phase III.7.3.2.1
## The Illuminator's Private Studio

Generated portrait customisation moves from the finished Character Ledger to
**Edit Adventurer**.

The Ledger keeps its centred finished portrait and the Bring Your Own Portrait
workflow. Edit Adventurer receives the full generated Workbench and persists
its recipe on save. If a custom image is active, Workbench changes update the
generated fallback underneath without replacing the custom image.

This gives III.7.3.3 — The Guild Wardrobe a permanent editing home.
