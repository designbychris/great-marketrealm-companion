# Apple Fructan Character Bible

The Apple Fructan Grocer is the Generation 2 visual benchmark.

## Benchmark requirements

- Compact rounded body.
- Large expressive face.
- Hero-scale leaves and a curled stem.
- Chunky hands and boots.
- Warm top-left lighting.
- Local-colour outlines.
- Layered cloth, leather, produce and facial details.
- Clear silhouette at 96 pixels.
