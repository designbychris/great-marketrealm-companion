# Auby's Desk Illustration Kit

Auby's Desk is the visual heart of the Guild Hall dashboard.

## Dayparts

- Morning — fresh parchment, warm sunrise, tea.
- Day — bright window, active workspace.
- Evening — amber lamp light and softer sky.
- Night — moonlight, stronger desk lamp, quieter atmosphere.

The browser chooses the daypart using the visitor's local clock. No exact time
is displayed and the state is decorative only.

Auby must always remain recognisably an aubergine.
